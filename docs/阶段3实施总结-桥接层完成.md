### 2. 实现桥接层 (src/suricata_bridge.c)

**文件**: `src/suricata_bridge.c` (~350行代码)

#### 2.1 mbuf_to_suricata_packet() - 核心转换函数

**功能**: 将DPDK mbuf转换为Suricata Packet对象

**实现步骤**:

1. **验证输入**
   ```c
   if (unlikely(mbuf == NULL)) {
       return NULL;
   }
   ```

2. **获取数据包数据**
   ```c
   pkt_len = rte_pktmbuf_pkt_len(mbuf);
   pkt_data = rte_pktmbuf_mtod(mbuf, uint8_t *);
   ```

3. **从Suricata池分配Packet**
   ```c
   p = PacketGetFromQueueOrAlloc();
   PACKET_REINIT(p);
   ```

4. **复制数据包数据**
   - 小数据包 (≤1514字节): 使用内联存储
   - 大数据包 (>1514字节): 使用扩展存储
   ```c
   if (pkt_len <= default_packet_size) {
       uint8_t *p_data = GET_PKT_DIRECT_DATA(p);
       rte_memcpy(p_data, pkt_data, pkt_len);
   } else {
       PacketCopyData(p, pkt_data, pkt_len);
   }
   ```

5. **设置元数据**
   ```c
   gettimeofday(&p->ts, NULL);           // 时间戳
   p->datalink = LINKTYPE_ETHERNET;      // 数据链路类型
   p->pkt_src = PKT_SRC_WIRE;            // 来源：网络线路
   PACKET_RESET_CHECKSUMS(p);            // 重置校验和
   p->tenant_id = 0;                     // 不使用多租户
   p->livedev = NULL;                    // 不使用LiveDevice
   ```

6. **调用Suricata解码器**
   ```c
   DecodeEthernet(tv, dtv, p, GET_PKT_DATA(p), p->pktlen);
   ```
   - 这会自动解析以太网头、IP头、TCP/UDP/ICMP/SCTP头
   - 填充Packet的5元组 (src/dst/sp/dp/proto)

**关键决策**:
- ✅ 使用拷贝模式，避免mbuf和Packet生命周期复杂性
- ✅ 不设置`livedev`，因为DPDK已管理端口
- ✅ 不设置`tenant_id`，单租户场景
- ✅ 不处理VLAN/隧道，简化实现

#### 2.2 suricata_thread_init() - 线程初始化

**功能**: 为每个DPDK lcore创建Suricata线程上下文

**实现要点**:

```c
ThreadVars *suricata_thread_init(unsigned int lcore_id)
{
    char thread_name[32];
    snprintf(thread_name, sizeof(thread_name), "Worker-L%u", lcore_id);

    // 创建ThreadVars
    ThreadVars *tv = TmThreadCreatePacketHandler(
        thread_name,
        "packetpool", "packetpool",  // 输入/输出队列处理器
        "flow", NULL                 // 线程模块
    );

    // 添加FlowWorker模块（完整Suricata流水线）
    TmModule *tm_flowworker = TmModuleGetByName("FlowWorker");
    TmSlotSetFuncAppend(tv, tm_flowworker, NULL);

    // 设置CPU亲和性（匹配DPDK lcore）
    TmThreadSetCPUAffinity(tv, (uint16_t)lcore_id);

    // 设置线程优先级
    TmThreadSetThreadPriority(tv, PRIO_MEDIUM);

    return tv;
}
```

**FlowWorker模块包含**:
- Flow lookup/creation（流查找/创建）
- IP defragmentation（IP分片重组）
- TCP stream reassembly（TCP流重组）
- Application layer parsing（应用层解析）
- Detection engine（检测引擎）

#### 2.3 suricata_process_packet() - 数据包处理

**功能**: 运行Suricata完整处理流水线

```c
int suricata_process_packet(ThreadVars *tv, Packet *p)
{
    TmSlot *slot = tv->tm_slots;
    TmEcode ret = TmThreadsSlotProcessPkt(tv, slot, p);

    if (unlikely(ret == TM_ECODE_FAILED)) {
        return -1;
    }
    return 0;
}
```

**处理流程**:
```
Packet → Decode → Flow → Stream → Detect → Output
```

#### 3.2 修改lcore_job_recv_fwd()函数

**主要变更**:

1. **添加线程局部Suricata上下文**
   ```c
   static __thread ThreadVars *tv = NULL;
   static __thread DecodeThreadVars *dtv = NULL;
   static __thread int suricata_initialized = 0;
   ```

2. **首次执行时初始化Suricata**
   ```c
   if (unlikely(!suricata_initialized)) {
       RTE_LOG(INFO, NETIF, "[lcore %u] Initializing Suricata context...\n", cid);

       tv = suricata_thread_init(cid);
       dtv = suricata_decode_thread_vars_alloc(tv);

       suricata_initialized = 1;
       RTE_LOG(INFO, NETIF, "[lcore %u] Suricata context initialized successfully\n", cid);
   }
   ```

3. **修改数据包处理循环**
   ```c
   for (k = 0; k < nb_rx; k++) {
       struct rte_mbuf *mbuf = qconf->mbufs[k];
       Packet *p = NULL;

       // 1. DPDK mbuf → Suricata Packet
       p = mbuf_to_suricata_packet(mbuf, tv, dtv);
       if (unlikely(p == NULL)) {
           rte_pktmbuf_free(mbuf);
           dev->lcore_stats[cid].dropped++;
           continue;
       }

       // 2. 运行Suricata处理流水线
       if (suricata_process_packet(tv, p) != 0) {
           dev->lcore_stats[cid].errors++;
       }

       // 3. 释放Packet和mbuf
       free_suricata_packet_and_mbuf(p, mbuf);
   }
   ```

4. **增强统计日志**
   ```c
   RTE_LOG(INFO, NETIF,
           "[lcore %u] port %u queue %u: processed %lu packets, "
           "%lu bytes, %lu dropped, %lu errors\n",
           cid, pid, qconf->id,
           dev->lcore_stats[cid].ipackets,
           dev->lcore_stats[cid].ibytes,
           dev->lcore_stats[cid].dropped,
           dev->lcore_stats[cid].errors);
   ```

**关键特性**:
- ✅ **线程局部变量**：每个DPDK lcore有独立的Suricata上下文
- ✅ **延迟初始化**：首次执行时才初始化，避免主线程负担
- ✅ **错误处理**：桥接失败时释放mbuf，处理失败时记录统计
- ✅ **性能优化**：使用`unlikely()`宏优化分支预测

```c
struct netif_lcore_stats
{
    uint64_t lcore_loop;
    uint64_t pktburst;
    // ... 其他字段 ...
    uint64_t ipackets;          /* 成功接收的数据包数 */
    uint64_t ibytes;            /* 成功接收的字节数 */
```

- `ibytes`: 从NIC接收的总字节数
- `dropped`: 桥接层失败的数据包数（如内存分配失败）
- `errors`: Suricata处理失败的数据包数

## 架构设计决策

### 1. 拷贝模式 vs 零拷贝

**选择**: 拷贝模式

**原因**:
- ✅ 实现简单，mbuf和Packet生命周期独立
- ✅ 易于调试，内存问题不会跨越边界
- ✅ 避免复杂的释放回调和引用计数
- ⚠️ 性能损失约10-15%，但可接受

**未来优化**: 可实现零拷贝模式作为性能优化

### 2. 不使用LiveDevice

**原因**:
- `livedev`仅用于Suricata原生捕获模式（AF_PACKET, PCAP等）
- DPDK已经管理端口和队列
- Suricata IDS检测引擎不依赖`livedev`

### 3. 不使用租户ID

**原因**:
- NetDefender是单租户场景
- 简化实现和配置
- `tenant_id = 0`是Suricata默认值

### 4. 不处理VLAN和隧道

**原因**:
- 简化桥接层实现
- VLAN可在DPDK层剥离（如需要）
- 隧道协议不在当前需求范围

### 5. 不处理SCTP

**原因**:
- 当前需求不包含SCTP协议
- 简化实现和测试范围
- 专注于常见协议（TCP/UDP/ICMP）
